# Ethara - Project Management Web App

A comprehensive MERN stack application for managing projects, assigning tasks, and tracking progress with role-based access control.

## Features

- 📋 **Project Management**: Create and manage projects
- ✅ **Task Management**: Assign and track tasks
- 👥 **Role-Based Access**: Admin and Member roles
- 🔐 **JWT Authentication**: Secure token-based authentication
- 📊 **Progress Tracking**: Visual progress indicators
- 🎨 **Clean UI**: Formal and professional interface

## Tech Stack

- **Frontend**: React (Plain JavaScript)
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## Getting Started

### Backend Setup
```bash
cd server
npm install
npm start
```

### Frontend Setup
```bash
cd client
npm install
npm start
```

## Environment Variables

Create `.env` files in both `server` and `client` directories with appropriate configuration.
